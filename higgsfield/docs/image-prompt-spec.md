# 图片切换分镜规范（srt-img-skill 格式）

> 从 2026-07 起统一使用该格式。旧版对应字幕 + 【】叙事段落格式已废弃。

每集在 `visuals/image-prompts.md` 中生成一个完整的图片切换分镜文档。

## 分镜结构

```markdown
# <视频标题>｜图片切换分镜

## 字幕分析

- 字幕条数：<N>
- 时间范围：00:00.000–<最后字幕结束时间>
- 总时长：<精确时长>
- 核心主题：<本集核心主题>
- 画面风格：<核心隐喻和叙事策略>
- 情绪节奏：<情绪变化路径>

## 切图节奏总览

| 图号 | 时间段 | 时长 | 类型 | 内容 |
|---:|---:|---:|---|---|
| 01 | 00:00.000–00:02.070 | 2.070s | 表演型 | <画面概况，不重复口播> |

## 逐张配图提示词

### 01｜画面标题

- 字幕：<此画面覆盖的原始口播，可合并多条>
- 画面意图：<通过什么具象场景表达什么概念（25字以内）>
- 画面描写：
  - 景别：<特写／近景／中景／全景等，以及构图重点>
  - 角色动态：<明确角色动作、视线与表情；必须包含动作动词>
  - 画面元素：<核心人物、道具、材质、光线与空间关系>
  - 前景动态：<近处可见的动作、遮挡、光影或物件变化>
  - 中景动态：<主体和核心道具正在发生的动作或关系变化>
  - 背景动态：<远景环境、天气、人群、光线或氛围变化>
```

## 字段规范

### 字幕分析
- 必须解析 SRT 的总条数、时间范围和总时长。
- 描述核心主题、画面视觉策略和情绪节奏变化。

### 切图节奏总览
- 五列：`图号`、`时间段`、`时长`、`类型`、`内容`。
- 类型只能是 `表演型`、`教学型` 或 `纯概念`。
- 从 `00:00.000` 连续排到最后一条字幕结束。
- 静音间隙并入相邻画面，不留空隙、不重叠。
- 前 30 秒（起点 < 30s）每张图最长 **3 秒**，之后最长 **6 秒**。
- 时长精确到三位毫秒。
- 尽量在字幕边界或自然语义停顿处切图。

### 逐张配图提示词

| 字段 | 要求 |
|---|---|
| 字幕 | 必须保留原口播文本，可合并多条相邻字幕 |
| 画面意图 | 短句（≤25字），解释具象画面要传达的概念或氛围，不得改写字幕 |
| 画面描写→景别 | 具体景别类型 + 构图重点 |
| 画面描写→角色动态 | 必须有动作动词（递/指/托/放/转/走/握/推等），不能只写"人物在画面中" |
| 画面描写→画面元素 | 描述核心道具、材质、光线、空间关系 |
| 画面描写→前景动态 | 近景处的动作、遮挡、光影变化 |
| 画面描写→中景动态 | 主体和核心道具的动作或关系变化 |
| 画面描写→背景动态 | 环境、天气、氛围变化 |

## 写作规则

- **贯穿角色**：默认主角为 小金（Xiaojin），如有其他角色必须标明职业/特征。
- **画内无文字**：不生成字幕、标题、图表数字或品牌标志；信息依靠道具、动作和构图表达。
- **描写要具体**：使用材质、光线、色彩、空间关系等具体元素，不得使用"画面丰富""氛围感强"等空泛词。
- **必有动作**：每张图至少有一个可见的角色动作。
- **动态定格**：即使是静态图片，也将"动态"写成定格瞬间中可被看出的动作、位移、光线或环境变化，而不是视频运镜指令。

## 本地生成与校准

本项目已内置 `tools\subtitle-image-storyboard`。先由人工完成逐图视觉计划 JSON，再执行：

```powershell
python tools\subtitle-image-storyboard\scripts\generate_storyboard.py <中文字幕.srt> <输出分镜.md> <输出提示词.txt> --visual-plan <视觉计划.json>
```

生成器会自动以中文字幕 SRT 回填两个时间表；不会再按整集字数重新分配时间。需要修复已有文件时可单独运行：

```powershell
python tools\subtitle-image-storyboard\scripts\calibrate_storyboard_timeline.py <中文字幕.srt> <image-prompts.md>
python tools\subtitle-image-storyboard\scripts\validate_storyboard.py <中文字幕.srt> <image-prompts.md>
```

校准器只修改“逻辑字幕段”和“切图节奏总览”的来源字幕、时间段和时长；逐张提示词、图片引用、图号、类型和内容不会被改动。
